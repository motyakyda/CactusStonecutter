# CactusSkins 🌵

Кастомные скины и плащи для Fabric — свои, без Mojang и без миграций. Скин видят все
игроки с модом, работает на любом сервере.

Одна кодовая база, девять версий Minecraft — через [Stonecutter](https://stonecutter.kikugie.dev).

## Как это выглядит для игрока

1. Кинуть jar в `mods`, запустить игру
2. Главное меню → **Skins** → **Подключить аккаунт**
3. Открывается браузер с кодом — указать свой ник, подтвердить
4. Готово. Дальше — библиотека: перетащил PNG в окно игры, кликнул превью, скин надет

Никаких токенов, паролей и полей «вставь ключ сюда». Мод хранит секрет сам.

## Сборка

```bash
# одна версия
gradle "Set active project to 1.21.11"
gradle :1.21.11:build

# все версии
for v in 1.16.5 1.17.1 1.18.2 1.19.2 1.19.4 1.20.2 1.20.4 1.20.6 1.21.11; do
  gradle "Set active project to $v" && gradle ":$v:build"
done
```

Готовые jar — в `versions/<версия>/build/libs/`.

CI собирает все версии на каждый push, готовые jar лежат в артефактах сборки.
Тег `v*` публикует релиз с jar-ами.

## Режим разработчика

Шестерёнка в правом верхнем углу экрана Skins: адрес Backend, замаскированный токен,
сброс кэша. Обычному игроку туда заходить не нужно.

## Backend

Cloudflare Worker + KV — код в отдельном репозитории `CactusSkins-Backend`.

| Эндпоинт | Что делает |
|---|---|
| `POST /api/pair/start` | выдать код привязки |
| `GET /api/pair/poll` | мод опрашивает статус привязки |
| `GET /api/me` | библиотека скинов (Bearer) |
| `POST /api/skins` | добавить скин (Bearer) |
| `POST /api/skins/activate` | надеть скин (Bearer) |
| `GET /skins/{nick}.png` | активный скин игрока |
| `GET /api/info/{nick}` | модель рук, наличие плаща |

## Стек

- Fabric Loader + Mixin
- Stonecutter — версионные комментарии `//? if >=1.20.2 {`
- LWJGL TinyFileDialogs — нативный файловый диалог на всех ОС
- Cloudflare Workers + KV — хранение
